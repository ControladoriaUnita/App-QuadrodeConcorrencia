Logos, cores, tipografia, tokens e componentes extraídos do Painel de Obras. Use esta página como referência para todos os projetos web da Unità. A especificação em texto está em docs/DESIGN_SYSTEM.md.

01 · Marca

Logotipos e elementos gráficos

Arquivos em apps/web/src/assets/brand/. O logo preto vai em fundo claro, o branco em fundo escuro. O acento do "à" é sempre laranja.

  • Faça: altura mínima de 28px em tela (48px na tela de login).
  • Faça: deixe uma área livre ao redor do logo de, no mínimo, a altura do "à".
  • Faça: use o padrão gráfico só como textura, sem interação (aria-hidden).
  • Faça: alt="Unità Engenharia" no logo; alt="" em imagens decorativas.
  • Não faça: recolorir o acento, distorcer, girar, aplicar sombra ou contorno.
  • Não faça: logo preto sobre grafite ou logo branco sobre fundo claro.
  • Não faça: símbolo "un" no lugar do logo quando há espaço para o logo completo.
  • Não faça: padrão gráfico com opacidade alta atrás de texto.

08 · Código

Tokens prontos para copiar

Fonte única: apps/web/src/styles/tokens.css (Tailwind v4). Sem Tailwind, troque @theme static { por :root {.

/*
 * Design tokens — Unità Engenharia. SINGLE SOURCE for colors, typography, spacing, radius,
 * shadows. Tailwind utilities (bg-primary, text-ink-900, rounded-card…) are generated from
 * these variables and `src/constants/tokens.ts` re-exposes them to TypeScript (charts).
 * Never hard-code a color anywhere else.
 */
@theme static {
  /* Brand — extracted from the official logo files */
  --color-brand-orange: #fe5000; /* acento do "à" / símbolo un */
  --color-brand-orange-line: #f05426; /* padrão gráfico "Diversos UN" */
  --color-brand-black: #000000; /* logotipo UNITÀ */
  --color-brand-ink: #231f20; /* símbolo un preto */

  /* Semantic */
  --color-primary: var(--color-brand-orange);
  --color-primary-hover: #e04700;
  --color-primary-soft: #fff1ea;
  --color-primary-foreground: #ffffff;
  --color-secondary: var(--color-brand-ink);
  --color-secondary-foreground: #ffffff;

  /* Neutral scale (warm, harmonises with the brand ink) */
  --color-ink-50: #f8f7f6;
  --color-ink-100: #f0eeec;
  --color-ink-200: #e2dfdc;
  --color-ink-300: #c9c4c0;
  --color-ink-400: #a19b96;
  --color-ink-500: #77716d;
  --color-ink-600: #57524f;
  --color-ink-700: #3d3937;
  --color-ink-800: #2b2827;
  --color-ink-900: #1a1817;

  --color-background: var(--color-ink-50);
  --color-surface: #ffffff;
  --color-border: var(--color-ink-200);
  --color-text: var(--color-ink-900);
  --color-text-muted: var(--color-ink-500);

  --color-success: #1e8a4c;
  --color-success-soft: #e7f5ec;
  --color-warning: #b7791f;
  --color-warning-soft: #fdf4e3;
  --color-error: #c62828;
  --color-error-soft: #fdecec;
  --color-info: #2563a8;
  --color-info-soft: #e8f0fa;

  /* Grid specific */
  --color-cell-manual: #fff4d6;
  --color-cell-issued: #e7f5ec; /* taxa emitida no mês */
  --color-cell-current-period: #fff1ea;

  /* Typography */
  --font-sans: 'Inter', ui-sans-serif, system-ui, -apple-system, 'Segoe UI', sans-serif;
  --font-display: 'Sora', 'Inter', ui-sans-serif, system-ui, sans-serif;

  /* Radius & shadows */
  --radius-control: 0.5rem;
  --radius-card: 0.875rem;
  --shadow-card: 0 1px 2px rgb(26 24 23 / 0.06), 0 1px 3px rgb(26 24 23 / 0.08);
  --shadow-overlay: 0 10px 30px rgb(26 24 23 / 0.18);
}

Checklist para um novo projeto

  • Copiar src/assets/brand/ e public/favicon.png
  • Copiar styles/tokens.css, styles/index.css, constants/tokens.ts, utils/cn.ts, utils/format.ts
  • Copiar components/ui/ e components/layout/
  • Carregar Inter e Sora, com lang="pt-BR" e theme-color #FE5000
  • Nenhum hex fora de tokens.css
